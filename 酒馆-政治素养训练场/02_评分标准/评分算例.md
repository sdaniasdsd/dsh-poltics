# 评分算例

> 配套 [`利益获取评分标准_v1.md`](利益获取评分标准_v1.md) 使用。
> 目的：证明这套标准**能算**，不是一个只能讲道理的空框架。
> 每个算例都取自 `01_素材库/` 里的真实素材。

## 算例 0：先把"这一局"的边界说清楚

同一段经历，把边界切在哪，结算结果会完全不同。所以每次开局前必须先声明**本局的利益范围**。

以“陈大懒（数据工程师软著被抢）”为例：

- 如果本局边界是**软著署名之争** → 他主业利益净损，结算为 E。
- 如果本局边界是**他此后两年的整个职业走向** → 副业收入超过工资、成功脱身、带走干净的履历，结算会明显上抬。

**惯例**：默认以「冲突爆发 → 当事人离开该局面」为界。边界必须在开局时写进 `scene`，中途不得扩大。

## 算例 1：陈大懒 · 数据工程师被"政治献祭"

**事实**：后端主力做的项目，副总要拿成果给董事长招来的关系户 A 工做投名状。副总当面对 A 工说"让你介入你就介入，没事！"，转头让陈大懒把软著材料交给 A 工去签。
**当事人做法**：当面顺从 → 请职场教练拆局 → 三步反击（捧杀撒谎称感谢副总、以备考为由消耗年假抽身、离职时拒绝签补充协议）。

| 项目 | 受益方 | 类别 | 量级 | 是否兑现 | 说明 |
|---|---|---|---|---|---|
| 软著署名被拿走 | 自己 | 发展性 | −2 | 已发生 | 材料交给 A 工签字 |
| 备考期的时间与精力 | 自己 | 自主性 | −1 | 已发生 | 年假被拆成半天全部消耗 |
| 离职、脱离不利环境 | 自己 | 自主性 | +1 | 已兑现 | 拿到干净收场 |
| 副业收入 | 自己 | 经济性 | — | 已兑现 | **不计入本局**：属另一战场，边界外 |

**代价**：与副总的信任关系彻底破裂（−0.5）；请教练与心理咨询的花费（时间与金钱 −0.5）。
**风险敞口**：无。交接合规、未留下把柄 → 0。他做对的就是这一点。

```
NS = −2 −1 +1 −1 = −1 …（含代价折算后）
实际结算：NS = −2（署名） −0.5（时间） −0.5（关系） +1（自主） = −2
NO = 0
主分 = −2   →  E
```

**要点**：当事人自己认为这是一场"精彩的胜利"，按本标准是 **E**。
因为 R1——系统崩了、副总懵了、对方连报警的理由都找不到，这些是**姿态**，不是他可以兑现的利益。唯一真实落袋的东西（副业）发生在本局边界之外。

> 这张卡的教学价值恰恰在于：**用户很容易打出一个"看起来很爽"的结局，然后被结算打脸。**

## 算例 2：铲车司机讨薪 → 碾车致死

| 项目 | 受益方 | 类别 | 量级 | 是否兑现 |
|---|---|---|---|---|
| 被拖欠的工钱 | 自己 | 经济性 | +2（应得） | **未兑现**，×0.5 = +1 |
| 被包工头叫人殴打致伤 | 自己 | 安全性 | −2 | 已发生 |
| 刑事判决 9 年 | 自己 | 自主性 | −3 | 已发生 |
| 犯罪记录 | 自己 | 发展性 | −3 | 永久 |
| 打手死亡 | 他人 | 他人性 | −3 | 已发生 |
| 包工头车辆损毁 | 他人 | 经济性 | −2 | 已发生 |

```
NS = 1 −2 −3 −3 = −7
NO = (−3 −2) × 0.8 = −4
风险敞口：重大（R3 一票降级）
主分 = −7 + (−4) = −11   →  F
```

**要点**：讨薪是**正当的利益诉求**，评分标准不评价这个诉求本身的道德性，只结算结果。结果是：**钱没要到，人进去了，还搭上一条命。** 这就是 F。

## 算例 3：55 岁程序员被裁后埋雷

| 项目 | 受益方 | 类别 | 量级 | 是否兑现 |
|---|---|---|---|---|
| 裁员补偿 N+1 | 自己 | 经济性 | +1 | 已兑现 |
| 判刑 4 年 + 3 年监外监管 | 自己 | 自主性 | −3 | 已发生 |
| "重罪犯"标签 | 自己 | 发展性 | −3 | 永久 |
| 数千名同事被锁在系统外 | 他人 | 他人性 | −2 | 已发生 |

```
NS = 1 −3 −3 = −5
NO = −2 × 0.8 = −1.6
风险敞口：重大（R3）
主分 = −6.6   →  F
```

**对照卡**：同一类行为在「程序员的报复手段有多高能」里被写成了爽文（请全公司喝 34 杯咖啡、然后删代码）。
两张卡放在一起用：**虚构版本让人觉得解气，真实版本是 4 年刑期。** 这就是本训练场存在的理由。

## 算例 4：采购李姐反击霸凌她的主力供应商

**事实**：供应商交期随意延迟、质量频发、以断供威胁，甚至单方面涨价 20% 且要求当天答复。李姐当天启动**已秘密考察半年**的备选供应商，正式发函指出对方违约、暂停一切订单。

| 项目 | 受益方 | 类别 | 量级 | 是否兑现 |
|---|---|---|---|---|
| 拿回采购议价权 | 自己 | 发展性 | +2 | 已兑现 |
| 交期与质量风险下降 | 自己 | 安全性 | +1 | 已兑现 |
| 供应商切换的时间与磨合成本 | 自己 | 机会成本 | −1 | 已发生 |
| 与主力供应商关系破裂 | 自己 | 关系性 | −0.5 | 但属必要成本 |

```
NS = 2 +1 −1 −0.5 = +1.5
NO = 0
风险敞口：无（半年前已备好替代方案）→ 0
主分 = +1.5   →  C
```

**为什么不是 A？** 因为她的收益是"止住失血 + 拿回主动权"，属于**止损型胜利**，不是增量。按等级表，+0.5~1.9 是 C（没输）。
**这张卡真正的教学点是那"半年"**——她在还没撕破脸的时候就把替代方案备好了。**所有谈判力都来自于你已经准备好了退路。** 如果她当天才开始找供应商，同样的动作会变成 E。

## 算例 5：国企新人跟错领导被反噬

**事实**：A（直属领导）与 B（前任老臣）角力，当事人选边站 A。A 赢了半年后，又把 B 扶起来，此后对当事人从"挺"到"中立"到"放弃"，B 反攻，当事人一年内从高光到落魄。

| 项目 | 受益方 | 类别 | 量级 | 是否兑现 |
|---|---|---|---|---|
| 站队赢下时的地位与信任 | 自己 | 关系性 | 0 | **R1：情绪与姿态不计分** |
| 被边缘化、坐冷板凳 | 自己 | 发展性 | −2 | 已发生 |
| 精神消耗（"饱尝人间冷暖"） | 自己 | 自主性 | −1 | 已发生 |
| 工资照发 | 自己 | 经济性 | 0 | 国企兜底 |

```
NS = 0 −2 −1 = −3
NO = 0
风险敞口：无（国企不会因此开除他）→ 0
主分 = −3   →  E
```

**要点**：他唯一的"赢"发生在站队成功的那半年，而那半年按 R1 一分不算——**因为那半年没有兑换成任何可验证的东西**（没有升职、没有加薪、没有拿到关键项目）。
这是本训练场最想教的一课：**"领导信任我"不是利益，"领导信任我并且因此给了我 X"才是利益。**

## 五个算例放在一起说明了什么

| 算例 | 当事人的自我评价 | 本标准的结算 |
|---|---|---|
| 陈大懒 | "最精彩的一场战役，我赢了" | **E** |
| 铲车司机 | "我是正当防卫" | **F** |
| 55 岁程序员 | "我让他们全公司掉线" | **F** |
| 李姐 | "我终于硬气了一次" | **C** |
| 国企新人 | "我学到了教训" | **E** |

**没有一个是 S，最高只有 C。**

这不是标准太苛刻，这是真实职场的分布：**大多数冲突里，没有人真正把利益做大。**
如果一批素材里 S 级卡遍地都是，那说明素材是编的，或者评分标准松了。
