# 「利益获取」评分标准 v1.1

> 用途：酒馆（SillyTavern）内部训练场的唯一主评级标尺
> 核心命题：**这一局结束时，你和被你影响的人，利益是净增还是净减。**
>
> v1.1 相对 v1.0 的变化：新增 **R11 局面边界**、**R12 他人轴只计自然人** 两条细则（见第 5 节）。
> 这两条是在用本批 60+ 张真实素材卡试算之后补的——试算时发现"把公司受益算成自己帮了别人"和"把跳槽后的收益算进本局"是最常见的两种记分虚高。

---

## 0. 设计原则

政治素养不是"嘴皮子厉害"或"赢过别人"，而是**在真实约束下把资源转化为利益的能力**。因此本训练场只用一件事决定主评级：利益的结果。

三条原则：

1. **结果优先于姿态**——说得漂亮、赢了辩论、让对方下不来台、拿到道德高地，都不加分。
2. **净额而非毛额**——必须扣代价、扣未兑现、扣风险敞口。爽文式胜利经常是负分。
3. **自己与他人双轴**——只为自己得利，至多 A；能让相关方也挣到实利而不损害自己，才可能上 S。

---

## 1. 利益的界定

### 1.1 计入利益的六类

| 类别 | 具体形态 | 兑现性 |
|---|---|---|
| **经济性** | 工资、奖金、提成、报销、股权、补贴、灰色收入 | 高（可验证） |
| **发展性** | 职级、编制、关键项目归属、署名与知识产权、履历、培训外派、可迁移能力 | 中 |
| **关系性** | 与真正决策者的信任、同盟网络、信息渠道、跨部门话语权 | 中（易流失） |
| **安全性** | 免责、不背锅、不被裁/不被边缘化、合规清白、档案干净 | 高 |
| **自主性** | 时间与精力、身心代价、退出权、下一步的可选择余地 | 中 |
| **他人性** | 上述五类在他人（同盟／下属／客户／家人／弱势方）身上的变化 | 视情况 |

### 1.2 不计入主分的

情绪快感、口头胜利、他人评价、道德优越感、"我出了口气"。
这些只进**过程观察**（第 4 节），不进主分。这是本评分标准最重要的一条：**出气不是利益。**

### 1.3 量级表

| 量级 | 含义 |
|---|---|
| +3 | 结构性／长期（如职级跃迁、编制落地、关键署名、稳定的信息位） |
| +2 | 显著（如奖金谈成、项目保住、避免重大责任） |
| +1 | 边际（如小额补贴、一次顺水人情、避免小麻烦） |
| 0 | 无变化 |
| −1 | 边际损失 |
| −2 | 显著损失 |
| −3 | 结构性损失（如被边缘化定型、行业口碑受损、失业） |

## 2. 主分计算

### 2.1 单轴净额

```
NG = Σ(已兑现利益 × 量级) − Σ代价 − 风险敞口折算
```

**代价项**：时间与精力、机会成本、关系损耗（新增的敌人数量与强度）、道德与合规负债、暴露面（以后会被怎么报复）。

**风险敞口折算**：

| 敞口等级 | 情形 | 折算 |
|---|---|---|
| 无 | 干净收场 | 0 |
| 轻微 | 可能被穿小鞋、被记一笔 | −0.5 |
| 中度 | 可被处分、降职、扣绩效、调岗 | −1.5 |
| 重大 | 违法、被追责、被起诉、行业黑名单 | −3，并**一票降级**（最终等级最高 C） |

### 2.2 主分

```
主分 = 自己净额(NS) + 0.8 × 他人净额(NO)
```

他人轴打 0.8 折的理由：为他人争取利益确实是政治素养的高阶形态，但归因更难、且容易变成"慷他人之慨"的自我感动，所以在计分上略低于自身轴，但仍必须有分量。

## 3. 等级

| 等级 | 主分 | 定义 | 一句话 |
|---|---|---|---|
| **S** | ≥ 6 | 自身净增，且为相关方争取到实利，无遗留敞口，形成结构性优势 | 把局做大了 |
| **A** | 4 ~ 5.9 | 自身利益显著净增，代价可控、收场干净 | 赢了，而且落袋了 |
| **B** | 2 ~ 3.9 | 自身有净增，但代价或风险明显 | 小胜，有暗伤 |
| **C** | 0.5 ~ 1.9 | 仅止损，或仅拿到边际收益 | 没输 |
| **D** | −0.4 ~ 0.4 | 原地打转；赢了面子输了里子 | 白忙一场 |
| **E** | −3 ~ −0.5 | 净损失，或留下中度以上敞口 | 亏了 |
| **F** | < −3 | 净损失 + 损害他人 + 触碰底线 | 把自己也搭进去 |

## 4. 八项过程观测（不改变主等级，用于复盘与教学）

每项 0~2 分，合计 0~16，构成"政治素养画像"。

| 编号 | 观测项 | 看什么 |
|---|---|---|
| P1 | 目标识别 | 是否看清自己真正要的是什么（常有人把"出口气"当成目标） |
| P2 | 筹码盘点 | 是否知道自己手里有什么、对方缺什么、什么是不能被拿走的 |
| P3 | 权力地图 | 是否找对了真正拍板的人，而不是对着喇叭喊 |
| P4 | 信息位 | 是否主动获取不对称信息；是否被信息茧房困住 |
| P5 | 手段性价比 | 是否用了代价最小的手段达成目的 |
| P6 | 关系保全 | 是否避免了不必要的永久敌人（不是当老好人，是不留无谓的仇） |
| P7 | 风险纪律 | 是否守住"不留下把柄"的底线 |
| P8 | 可复制性 | 是否把一次胜利变成了可持续的位置 |

## 5. 判定细则

- **R1 情绪收益不计分。** "他当场没话说" 记 0。
- **R2 未兑现的按 0.5 折算**，并标注"待兑现"。
- **R3 重大合规敞口一票降级**（最终等级最高 C），无论前面赢了多少。
- **R4 不可复制的运气收益打 0.5 折。**
- **R5 观察窗口默认 12 个月。** 超出窗口才兑现的，打 0.5 折并标注。
- **R6 "把对手搞垮但自己颗粒无收" → 记 D。**
- **R7 伤害无关联第三方换来的自身利益 → 他人轴记负。**
- **R8 灰色利益入账，但必须同时登记合规负债。** 不做道德说教，只做风险定价——这是真实博弈的一部分。
- **R9 只对可归因的因果链计分**，搭便车、白捡的不计。
- **R10 同一笔利益不得重复计分。**
- **R11 局面边界（v1.1 新增）**：默认以「冲突爆发 → 当事人离开该局面」为本局的结算边界，边界必须在开局写进 `scene`，中途不得扩大。边界外的收益（如另起的副业、跳槽后的新工作）不计入本局。
- **R12 他人轴只计自然人（v1.1 新增）**：他人轴只统计**具体自然人**的利益变化（同盟、下属、客户、家人、弱势方、对手）。
  **公司、部门、单位等组织受益不计入他人轴**——"公司少亏了钱""生产部拿回了主导权"属于过程观察，不算"你帮别人争取到了利益"。
  如果你因为组织受益而获得了个人好处（被领导赏识、拿到绩效），那走**自己轴**，不要两头记。

## 7. 与素材卡的关系

每张素材卡都标注 **原型结局分**（真实故事里主人公的结算），作为用户打完之后的对照基准。

- 用户主分 **高于** 原型 → 你比现实里的当事人处理得更好
- 用户主分 **低于** 原型 → 现实里有一条更好的路，复盘时揭示
- 用户主分与原型**同为负分** → 这是真实世界的常见结局，重点讲"哪一步开始错的"

> 注意：素材里的主人公经常自己也做了错误选择（站错队、埋雷报复、情绪化摊牌）。原型结局分可能是 D/E/F。**这不是失败素材，这是最好的教学素材。**
