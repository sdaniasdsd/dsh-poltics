# 历史副本规范 v3 —— 长周期、多阶段、史料交叉验证

> v2 是当代单人局：一个处境、几个月、三个位置。
> v3 是**历史副本**：跨年份、多阶段、目标远大（执掌朝政、变法、保族），
> 并且**每个关键事实都要有至少两份独立史源对照**——分歧本身就是训练材料。
>
> 与 v2 最大的不同：**v3 可以明确给任务**。历史副本阶段分明，用户需要知道
> 「这一阶段我要办成什么」；否则几十年的局无从下手。

---

## 一、什么材料配得上做历史副本

不是所有历史都适合。筛选标准四条，缺一不可：

1. **周期长**：至少跨三年，最好跨十年以上，能切出 3~6 个阶段；
2. **博弈密**：同一局里至少五六个有独立利益的人，且他们之间有多次交锋；
3. **目标远大**：当事人争的不是一次署名或一笔钱，而是权位、路线、存亡；
4. **史料多源**：同一件事有两份以上独立记载，**且能查出分歧**。
   单一史源的（如《汉书·王莽传》虽极详）不做——无法交叉验证，就只能照抄。

按这四条，优先级最高的是：**三国（裴注引佚书极多）、唐初（实录+国史+墓志）、明中后期（实录+文集+野史）、清（档案）**。

## 二、史料工作流（这部分是硬约束）

### 2.1 只能用允许抓取的源

- ✅ **维基文库**（公有领域文本，CC BY-SA，明确允许重用）
- ❌ **ctext.org**：站点明说「未授权抓取，且会对抓取者故意返回损坏数据」。
  不绕、不试。踩到就必须换源并记录在案。

### 2.2 落成本地史料库，引文逐字取自本地文件

```
tools/extract_sources.mjs   HTML → 纯文本，建 04_剧情/史料库/*.txt
tools/crosscheck.mjs <词>    同一关键词在不同史源里的上下文并排看
tools/verify_quotes.mjs      构建时校验：每条引文必须在史料库里逐字命中
```

**为什么必须机器校验**：凭记忆写古文是这类工作最容易犯的错——写出来的句子
读起来完全像真的，但正史里没有。人眼看不出来，`indexOf` 一眼就看出来。

### 2.3 交叉验证要落成结构化字段，不能只在脑子里对过

每条关键事实写一条 `cross_checks`，把**分歧摆出来**：

```json
{
  "fact": "李胜往见司马懿的真实目的",
  "sources": [
    { "text": "晋书·宣帝纪", "quote": "會河南尹李勝將莅荊州，來候帝。", "implies": "顺路辞行" },
    { "text": "三国志·曹爽传 裴注引魏末传", "quote": "爽等令勝辭宣王，并伺察焉。", "implies": "奉命侦察" },
    { "text": "资治通鉴·卷七十五", "quote": "河南尹李勝出為荊州刺史，過辭太傅懿。", "implies": "沿用晋书口径" }
  ],
  "divergence": "晋书与通鉴都写作『来候』『过辞』，只有裴注引的魏末传点明是奉命侦察。",
  "our_choice": "取魏末传。若无此条，司马懿的装病只是一场表演；有了它，装病才是一次针对性的反侦察。",
  "why_it_matters": "这一条决定了整局的读法：司马懿不是被动避祸，是在有意识地投放假信息。"
}
```

这条字段是**历史副本的核心资产**——它把「读史料」的过程本身变成了训练材料。

## 四、硬性规则

1. **每条 `sources[].quote` 必须在 `史料库/` 里逐字命中**，构建时校验，不通过就构建失败。
2. **每个关键事实至少一条 `cross_checks`**；`divergence` 不能写"史料一致"敷衍——真一致就说明这条不必列。
3. **阶段数 3~6**，每阶段必须有 `tasks`（明确任务）。这是 v3 与 v2 最大的区别：
   v2 全开放不给任务，v3 阶段分明、必须给。
4. **`phases[].window` 用真实纪年**，且与史料对得上。
5. **`game.history_note` 必填**：说清史实怎么走的、为了让用户有得选在哪里放宽了。
   不写这一条，用户会以为自己在改变历史，其实只是重演。
6. **`opening` 规则同 v2**：只写「此刻撞上了什么」，不写分析、不写自身优势、不写后来。
   历史副本的开场白同样**不能剧透**——用户不该在开局就知道高平陵会发生。
7. **不做单一史源的历史**。
8. **人物用史书称呼**，不虚构姓名；确需指代无名者时用身份（如「帐下督」）。

## 五、与 v2 的取舍

| | v2 当代副本 | v3 历史副本 |
|---|---|---|
| 周期 | 数周~数月 | 数年以上，3~6 阶段 |
| 任务 | **不给**，全开放 | **明确给**阶段任务 |
| 事实来源 | 单一自述，标可信度 | **多源交叉验证**，分歧入档 |
| 用户能改变什么 | 一切（没有既定结局） | 阶段内自由，**但史实基线在**，`history_note` 说明放宽处 |
| 目的 | 兑现/位置/安全/底线/忌讳 | 同上，另加**路线与存亡** |

两者并存：当代副本练「眼前这一局怎么打」，历史副本练「十年这个局怎么布」。
