## 渠道可用性实测（2026-09 更新）

| 渠道 | 能否直连抓取 | 实测结论 |
|---|---|---|
| **知乎** | ✅ 可以 | 问答页与专栏都能拿到正文。注意知乎只渲染首屏前 3~5 条回答，`-MaxAnswers` 调大也拿不到更多——**要拿全量回答必须滚动触发懒加载**（当前脚本没有做这一步，是下一轮的改进点）。 |
| **B 站** | ✅ 可以 | 视频页正文（UP 主写的长文/简介）能抓到，且出过硬素材（唐志强讨薪案）。**但搜索结果以自媒体讲解为主**（"如何甩锅""七个话术"），不是一手经历；真正有价值的是**打工人 vlog**。 |
| **抖音** | ✅ **可以（已改写结论）** | 详见下面「抖音实测」。**登录墙只在 `/search/`**，详情页不需要登录。用 `tools/collect_douyin.ps1` 抓取。 |
| **web_fetch 工具** | ❌ 不行 | 本机走 fake-IP 代理（DNS 解析到 198.18.x.x），`web_fetch` 的安全检查会判定为非公网地址并拒绝。**必须走 Tabbit 真实浏览器。** |
| Bing / Google（站内搜） | ❌ 不行 | Bing 在代理下 `ERR_TOO_MANY_REDIRECTS`。**发现环节改用本项目的 `web_search`，它能索引到抖音链接。** |

## 抖音实测（登录墙到底在哪）

| 路径 | 是否需登录 | 实测结果 |
|---|---|---|
| `/search/{关键词}` | ❌ **要登录** | "登录后即可搜索更多精彩视频"，只有扫码/验证码登录入口 |
| 首页 / 精选 / 推荐流 | ✅ 不要 | 正常渲染，含视频文案 |
| `/hot` 热榜 | ✅ 不要 | 正常渲染，并直接给出 10 条 `/video/{id}` 链接 |
| `/video/{id}`、`/shipin/{id}`、`/note/{id}` | ✅ **不要** | 标题、文案、话题、播放/点赞/评论/分享数、发布时间、作者全部可读 |
| 评论区 | ✅ **不要** | 前 ~10 条评论 + 可展开的回复都能读到；只有**发表**评论要登录 |
| 相关视频列表 | ✅ **不要** | 一页给 15+ 条同题材条目，**这是天然的发现图谱** |
| 「查看AI文稿」（口播转写） | ⚠️ 未打通 | 按钮存在，但需要先滚动到可视区再点击；本轮点击未命中，待下轮解决 |

### 所以完整链路是（每段都已实测）

```
发现   web_search（能索引到 douyin.com/shipin|video|note/{id}）
  ↓
扩散   进入任一详情页 → 从「相关视频」列表横向爬同题材
  ↓
取内容 文案 + 评论区（评论区往往就是"我也遇到过"的真实经历聚集地）
  ↓
落盘   tools/collect_douyin.ps1  →  raw/dy*.json
```

命令：

```powershell
& tools\collect_douyin.ps1 -UrlsFile tools\urls_douyin.txt -RequestId dy01
```

实测样本：3 条 URL 全部成功，抓到 20 条评论 + 12 条相关视频。其中 `/note/7501350363354828070`（"进厂 16 天，今天被人家说做事慢"）的评论区直接给出了多条一线自述，例如"我干活也不是特别快的那种……难道我们干的慢的就不配进厂工作嘛"、"以前在流水线的时候，有新来的女孩……我看不得那个无力无助的样子，帮了她"。

### 如果要把抖音吃透，还差一步

在 Tabbit 里**扫码登录一次**。Tabbit 用的是你自己的浏览器会话，登录后站内搜索和完整评论区就都能用。这一步需要你亲手扫码，我代做不了。

**不建议**去逆抖音的接口签名（a_bogus / X-Bogus）：那是持续对抗的，稳定性极差；而我们要的是文本素材，绕开渲染层去搞接口不划算。

## 下一轮建议的采集策略

1. **按问题页批量采（知乎）**：知乎一个问题页动辄几百个回答，`collect.ps1` 的 `-MaxAnswers` 调到 15~20 并**先滚动到底触发懒加载**，一次可拿到十几个独立经历，效率远高于逐条文章。
2. **补判例型素材**：法院判决书、纪委通报、事故调查报告是**唯一有权威结算的素材**，用来校准 `proxy_score` 的可信度。
3. **抖音走新链路**：`web_search` 找 `/shipin|/video|/note` 链接 → `collect_douyin.ps1` 抓文案+评论 → 用「相关视频」横向扩散。评论区是"同类经历"的高密度矿脉。
4. **B 站补打工人 vlog**：抽取视频页 UP 主正文 + 评论区。
5. **补「查看 AI 文稿」**：抖音口播视频自带字幕转写，打通后可以把长口述直接变成文本素材（本轮未打通，见上）。
6. **警惕"故事号"**：知乎专栏 / 搜狐故事号里带完整对白、戏剧化开场白和总结陈词的长文，多数是叙事性写作。已按 `fidelity` 字段标注，采信时以降级处理。
