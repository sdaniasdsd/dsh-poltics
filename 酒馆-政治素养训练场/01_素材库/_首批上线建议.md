# 首批上线建议

> 60+ 张卡不可能一次全上。这份文件给出**先上哪些、按什么顺序上**。
> 排序依据不是"哪张最精彩"，而是**哪张最能改变用户的决策习惯**。

---

## 一、开营包（用户第一次玩，必须先建立"结算感"）

**目的**：先让用户被结算打脸一次，他才会认真对待后面的每一句台词。

| 卡号 | 用途 |
|---|---|
| `E-09` 品质经理当众问我杀不杀人 | 开局压力最大，且用户的直觉反应（当场辩解）几乎必错 |
| `G-17` 背锅的五种可能 | 给框架，不给定论 |
| `E-01` 背锅三个月换来绩效合格 | 揭示"行吧"两个字的复利代价 |
| `G-16` 事事要留痕 | 给出可立刻执行的动作 |
| `E-10` 副总拿我的成果做投名状 | 第一张"成果被截胡"的卡，检验用户是否分得清"出气"和"落袋" |

**这一包结束后，用户应该记住一句话**：*情绪收益不计分。*

---

## 二、灰色利益包（本套素材里最锋利的一批，建议单独成营）

真实、有判例、有数字，且**评分标准在这里最反直觉**：吃回扣的人可能得 B，举报的人可能得 E。

| 卡号 | 用途 |
|---|---|
| `P-11` 人生中的第一笔回扣 | 门槛不是金额，是第一次伸手；按 R8 只做风险定价 |
| `P-10` 盗版书贩子的账本 | 七个人的七种结局，展示"暴露面不在你手里" |
| `P-12` 工地发票人的回扣 | 打破"回扣只是采购的事"的错觉 |
| `P-02` 举报你的人，就是给钱的人 | 反直觉案例：送钱的人亲手举报你 |
| `P-01` 选了贵 3% 的供应商 | 干净的人被匿名举报，**举证责任在你** |
| `P-13` / `P-14` | 主动认错反而被卖；一把手不签，副手担责 |

> 这一包必须配 `P-07`（买刀片，毁在提拔档口）作为收尾：能力越强越容易失去敬畏。

## 三、位子包（晋升、竞聘、空降）

| 卡号 | 用途 |
|---|---|
| `G-01` 口头许诺我当主管，人却空降了 | 空头支票的标准拆解 |
| `G-15` 口头提拔要"让一让" | 同一原型的另一种解法，形成张力 |
| `G-03` 竞聘公告发了，我是不是陪跑 | 教用户问出那个关键问题：*事前有没有领导跟你打招呼* |
| `G-04` 公告发布那天结局就写好了 | 国企竞聘的制度性解读 |
| `G-08` ↔ `G-09` | **镜像对**：落袋为安 vs 先别树敌，逼用户选边 |
| `G-14` 国企一把手从来都是给关系户的 | 权力地图，不是鸡汤 |

---

## 四、镜子包（用对照卡破除单一叙事）

这是本套素材最独特的设计：**同一件事，两个版本，两种结局。**

| 对照 | 你想让用户看到什么 |
|---|---|
| `E-02`（删库换顾问费，爽文）**↔** `E-07`（埋雷报复，判四年） | 文学里的解气 vs 判决书里的四年 |
| `S-10`（酒桌是试探的媒介）**↔** `S-11`（谁是发工资的就听谁的） | 同一张酒桌，两种活法 |
| `G-12`（跟错人被反噬）**↔** `G-18`（外公坚决不站队） | 站队的代价 vs 不站队的代价，都不是免费的 |
| `G-08` ↔ `G-09` | 及时兑现 vs 静观其变 |

## 五、基层包（工人线，节奏和监督关系与白领完全不同）

| 卡号 | 用途 |
|---|---|
| `W-12` 为什么挨欺负的偏偏是新来的大学生 | 心理机制，不是个人恩怨 |
| `W-02` 三个月后我有能力决定他们的利益 | 基层唯一的硬通货是"你能影响他的利益" |
| `W-11` 中介卡着不让你转正 | 三方利益链，用户会第一次看清自己的位置 |
| `W-08` 做了 90% 的设计，拿了 C | 口头承诺 vs 最终结果 |
| `W-09` 国企派遣小时工被老员工刁难 | 一问就被骂的处境里，"问"这件事本身怎么设计 |

---

## 六、必须**暂缓**上线的卡

| 卡号 | 原因 |
|---|---|
| `S-09`、`E-02`、`G-07` | `fidelity = 疑似虚构`。可以作为"镜子包"的对照物，但**不能作为主卡**——用户一旦发现素材是编的，会怀疑整套评分 |
| `S-02`、`S-04`、`S-06` 等方法型/无结局卡 | `proxy_score` 为空，用户打完之后没有对照基准，挫败感强。适合作为"训练补充"而非主剧本 |
| `W-05` 铲车司机讨薪碾车致死 | 极端案例（F 级）。**建议只作为收尾警示**，不作为可玩的剧本——让用户"扮演"一个后来判了九年的人，体验不好，也容易跑偏 |

---

## 上线顺序建议

```
第 1 营  开营包（5 张）        →  建立"情绪不计分"的肌肉记忆
第 2 营  位子包（6 张）        →  学会看权力地图
第 3 营  灰色利益包（7 张）    →  学会给风险定价
第 4 营  基层包（5 张）        →  换一套生存逻辑
第 5 营  镜子包（4 组 8 张）   →  破除单一叙事，形成判断力
收尾     极端案例（2 张）      →  知道底线在哪
```
