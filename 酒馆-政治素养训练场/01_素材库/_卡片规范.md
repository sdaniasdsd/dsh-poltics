# 训练场素材卡 · 数据结构规范 v1

每张卡是一个 JSON 对象。多个卡组成一个 JSON 数组，落在 `01_素材库/cards/<role>.json`。

```json
{
  "id": "S-01",
  "role": "sales | engineer | procurement | worker | general",
  "title": "卡片标题（15 字以内，抓冲突，不要用原文标题）",
  "source": {
    "url": "原始链接",
    "platform": "知乎 | 知乎专栏 | 搜狐 | 腾讯云 | 工劳短视频平台",
    "author": "原文署名，没有就写「未署名」",
    "batch": "sales01 / eng01 / buy01 / wrk01 / gen01 / b01"
  },
  "type": "经历型 | 案例型 | 判例型 | 方法型",
  "scores": { "drama": 4, "conflict": 5, "teachability": 5 },

  "scene": "一句话场景，训练场开场白用它。必须包含：你是谁、面前是谁、当下要做的决定。",
  "setting": "3~6 句背景：行业、公司性质、你的位置、局是怎么形成的。",
  "cast": [
    {
      "name": "A（或原文称呼）",
      "position": "职务/关系",
      "surface": "表面上他要什么、说什么",
      "hidden": "实际上他要什么（这是训练场的核心，NPC 的隐藏动机）",
      "leverage": "他手里有什么筹码"
    }
  ],
  "stakes": {
    "self": ["我要保住/争取的具体利益，逐条列"],
    "others": ["其他人的利益敞口"]
  },
  "conflict_point": "一句话说清核心冲突：谁要拿谁的什么，卡在哪。",
  "escalation": ["按时间顺序的 3~6 个升级节点，每个节点一行"],
  "info_asymmetry": "谁掌握了谁不知道的信息。这一项没写清楚，卡就不能用。",
  "protagonist_actions": ["当事人实际做了什么，逐条写，带原话更好"],
  "outcome": {
    "self": "当事人自己的利益净结果（拿到什么、丢了什么）",
    "others": "他人的利益净结果",
    "cost": "付出的代价（时间、关系、身心、机会）",
    "risk": "遗留的风险敞口（无 / 轻微 / 中度 / 重大 + 依据）"
  },
  "proxy_score": {
    "self_net": 0,
    "other_net": 0,
    "main": 0,
    "grade": "S|A|B|C|D|E|F",
    "reason": "为什么这么结算，3 句以内。必须引用《利益获取评分标准_v1.md》的规则编号（如 R3、R6）"
  },

  "lessons": ["这张卡要教会用户的政治素养考点，3~5 条，每条一句人话"],
  "branches": ["训练场里可以让用户做的关键选择，3~5 个。要写出「选 A 会怎样、选 B 会怎样」的走向，但不要写成攻略"],
  "evidence": [
    "从 raw 文件里逐字复制的原文片段，2~4 段，每段 20~120 字。用于核对卡片没有编造。"
  ],
  "fidelity": "直接转述 | 有加工（叙事性写作，可能有虚构细节） | 疑似虚构",
  "fidelity_note": "怎么判断的，一句话"
}
```

## 硬性规则

1. **`evidence` 必须逐字来自 raw 文件**，不得改写、不得翻译、不得合并。写完卡片后用 PowerShell 在 raw 文件里 grep 校验每段 evidence。
2. **不得编造**人物姓名、公司名、数字。原文没有的就写「未提及」。
3. `fidelity` 必须诚实标注。知乎专栏里带完整对话、有戏剧化开场白和总结陈词的长文，多数是**叙事性写作**，标 `有加工`；真实判决、法院通报、抖音当事人自述标 `直接转述`。
4. `proxy_score` 严格按 `02_评分标准/利益获取评分标准_v1.md` 计算：
   - 情绪收益不计分（R1）
   - 未兑现利益 ×0.5（R2）
   - 重大合规敞口一票降级，最高 C（R3）
   - 把对手搞垮但自己颗粒无收 → D（R6）
   - 伤害无关联第三方换来的自身利益 → 他人轴为负（R7）
   - 灰色利益入账同时登记合规负债（R8）
5. `scene` 和 `cast[].hidden` 是训练场的命门：**场景必须能让用户在 30 秒内知道自己站在什么局里**；**每个关键 NPC 必须有表面诉求和隐藏诉求的落差**。
6. 输出必须是**合法 JSON**（UTF-8 无 BOM）。写完后用
   `Get-Content -Raw -Encoding UTF8 <file> | ConvertFrom-Json` 校验通过。
7. 卡片按 `scores.drama + scores.conflict + scores.teachability` 从高到低排序。
