# dsh-poltics · 政治素养训练场

用 AI 角色扮演练政治素养。**30 篇可打的局：20 篇当代职场 + 10 篇历史长局**，配 DSH 酒馆插件运行。

不是让 AI 给你编一段戏看。每一篇是一个有**多方利益、明确阶段任务、可结算**的博弈局，
你要在里面选一个位置，用第一人称把它走完。

---

## 这套东西和普通角色卡的区别

**一、每篇都是一个局，不是一个场景**

每个位置有他的：手里有什么（筹码）、能被谁否掉（否决权）、押了什么、怕什么、不能做什么、
能做什么。这些是**写死在卡里**的，模型不能随手改。当代篇 3 个位置，历史篇 4 个位置。

**二、目标分五层，不是一句话**

```
兑现  我要拿到什么实际的东西
位置  我要坐到哪个位置上
安全  我要避免什么落到我头上
底线  什么是我绝不放弃的
忌讳  什么是我绝不能做的
```

结算按这五层 + 代价轴（时间、关系损耗、信用负债、暴露面）逐条判定。

**三、历史篇的每句引文都机器校验过**

10 篇历史副本共 **272 条引文**，全部从维基文库抓成本地语料后**逐字比对**；
构建脚本把"逐字命中"做成前置条件，对不上就构建失败。
**史料库共 154 份 / 约 189 万字**全部在仓库里，你可以自己复核。

**四、关键史实写成「交叉验证」，标明分歧与取舍**

不是"据史书记载"糊过去。每篇有 5~6 处交叉验证，写清：哪几处史料互相矛盾、
**我为什么选了这个说法**、这件事为什么重要。

举几个真实例子：

| 副本 | 交叉验证的是什么 |
|---|---|
| H-03 王莽 | 唯一详细记载他的史料，全部出自**取代他的那个朝代** |
| H-05 李世民 | 《大唐创业起居注》写于玄武门之变**之前**，两《唐书》在其后 |
| H-06 武则天 | 杀女一事，**最早的《旧唐书》本纪里根本没有** |
| H-08 张居正 | 史料自己承认自己在猜（「窃谓两说或出臆度，未足深信」） |
| H-10 李鸿章 | 最生动的谈判逐字记录，**是谈判对手一方整理的** |

**五、演出规则强制"有人说话"**

AI 拿到设定后默认会写旁白。所以每张卡都带：常驻世界书的演出规则、
`mes_example` 对话示例、以及写死在后置指令里的开场结构——
**每一轮必须有在场的人开口，结尾必须留一个你能直接接的话头**。

## 工具

管线是 **提取 → 校验 → 构建**，校验是构建的前置条件。

| 脚本 | 作用 |
|---|---|
| `tools/extract_sources.mjs` | 把抓下来的 HTML 史料转成纯文本语料 |
| `tools/verify_quotes.mjs` | **逐字**校验每篇副本的引文是否真在语料里 |
| `tools/verify_openings.mjs` | 校验开场与关卡是否符合"活场景 + 背景说明"规范 |
| `tools/build_cards.mjs` | 当代副本 → 角色卡 |
| `tools/build_cards_v3.mjs` | 历史副本 → 角色卡（引文校验是前置条件） |
| `tools/apply_stagecraft.mjs` | 给卡片补演出规则与对话示例（幂等） |
| `tools/crosscheck.mjs` | 在史料库里查一个词的所有出处与上下文 |
| `tools/qa_scenarios.mjs` | 结构 / 卡层 / 提示词权重的质检报告 |

```bash
node tools/verify_quotes.mjs      # 272 条引文逐字校验
node tools/verify_openings.mjs    # 151 段开场与关卡的结构校验
node tools/build_cards_v3.mjs     # 构建（校验不过就不构建）
```

## 素材来源

**只用维基文库**（公有领域 / CC BY-SA）。所有引文可回溯到具体条目 URL，
每篇副本的 JSON 里都记着 `local`（本地文件）与 `url` 两个字段。

抓取时明确放弃了 ctext.org——该站有反爬声明且会故意返回损坏数据，不适合作为校验源。
详见 `酒馆-政治素养训练场/04_剧情/_验证记录.md`。
